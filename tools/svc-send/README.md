# SVC → 대시보드 보내기 (1단계 · 반자동)

회사 SVC 화면에서 받은 수선실적·자재실적 엑셀을 **버튼 한 번으로 대시보드 업로드 화면에 넘기는** 브라우저 스크립트입니다.
적재(올리기)는 대시보드 화면에서 **사람이 검사 결과를 보고 누릅니다** — 자동으로 표를 바꾸지 않습니다.

## 설치 (한 번만)

1. 크롬에 **Tampermonkey** 확장을 설치합니다(회사 보안 규정상 확장 설치가 허용되는지 먼저 확인).
2. Tampermonkey → 「새 스크립트 만들기」 → 이 폴더의 `gst-svc-send.user.js` 내용을 통째로 붙여 넣고 저장합니다.
3. SVC 화면을 엽니다 → 주소창 옆 Tampermonkey 아이콘 → **「이 사이트에서 «대시보드로 보내기» 켜기」**.
   - 켠 사이트에서만 돕니다. 회사 주소는 이 파일·저장소 어디에도 적지 않습니다(저장소가 공개라서).

## 쓰는 법

1. SVC 에서 평소처럼 기간을 넣고 조회 → **엑셀 다운로드**.
2. 화면 오른쪽 아래 「GST 대시보드로 보내기」 판에 **보낼 파일**이 뜹니다.
   - 안 뜨면(SVC 가 서버에서 바로 내려주는 방식이면) 받은 파일을 그 판에 **끌어다 놓거나** 「파일 고르기」.
3. 「어느 표에」 — 수선실적 / 자재실적 고르기 → **「대시보드로 보내기」**.
4. 대시보드 업로드 화면이 새 창으로 열립니다.
   - 처음 한 번은 「다른 화면에서 파일을 보내려 합니다 — 허용?」을 묻습니다 → **허용**(이 PC 에서는 다시 안 묻습니다).
   - 대시보드 로그인이 풀려 있으면 그 창에서 로그인합니다.
5. 검사 결과(열 맵핑 · 새 값 · 키 중복)를 확인하고 **「올리기」**. 넣는 방식은 기본 「겹치는 구간만 교체」입니다.

## 지키는 것

- **로그인 정보를 다루지 않습니다** — 이미 로그인해 둔 SVC 탭 안에서 돌고, 아이디·비밀번호를 읽거나 저장하지 않습니다.
- **변환·검사·적재 규칙은 대시보드 업로드 화면 한 벌**입니다. 이 스크립트는 파일을 건네기만 합니다(두 벌이면 같은 자료가 다른 숫자가 됩니다).
- 대시보드는 **이 창을 연 창(opener)이 보낸 · 허용한 출처의 · 엑셀/CSV(60MB 이하)** 만 받습니다.

## 다음 (2단계)

1단계가 안정되면 늘 켜 두는 PC 에서 예약 실행으로 조회·다운로드·보내기를 사람 없이 돌리고, 결과를 알림으로 받게 바꿀 수 있습니다.
그때는 SVC 화면의 메뉴·단추 구조(스크린샷)가 필요합니다.
