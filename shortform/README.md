# GST 창립 25주년 숏폼 — «아무 일도 안 일어난 25년»

실사·사진·유명 음원 없이 **HTML/CSS/SVG 모션그래픽을 프레임 단위로 캡처**해 만들었고, BGM·효과음은

## 컨셉

「지난 25년, GST에는 아무 일도 안 일어났습니다.」로 시작하는 반전 서사.
실란은 불이 붙지 않았고, SF₆는 남지 않았고, 온도는 흔들리지 않았고, 공장은 멈추지 않았다 —
네 번 모두 같은 자리에 같은 도장 「**없었습니다.**」가 찍힌다 →
그 «아무 일»의 뒤에 **스크러버와 칠러**가 있었다(365일 24시간 × 25년 = 약 219,000시간) →
**그 기계들의 이름은 대지·강·숲·물이었다**(GAIA · GARAM · SOOPIA · AQUA) →
아무 일도 안 일어나게 하려고 꽤 많은 일을 했다(2001 창업 · 2006 코스닥 · 여섯 나라 · 수출의 탑) →
**다음 25년은 이미 시작됐다**(액침냉각) → **그 길을 정한 분들, 그리고 모든 임직원** →
「아무 일도 없게 하는 것. 그게 우리가 25년 동안 한 일입니다.」 →
**GST GROUP(GST · EST · ROBOCARE)** · 「다음 25년도, 아무 일 없이.」

패러디는 없다. 웃음은 «담담한 반전»(귀뚜라미·굴러가는 풀·노란 스탬프)에서, 뭉클함은 마지막 15초에서 온다.
규정대로 영상 안에 팀명·제출자명은 없다.

표시 순서는 배열 순서이고, 큐 축 순서와 달라도 된다.
⚠ **드럼만은 예외로 «출력 시각»에 직접 얹는다**(`bgm.cjs` 의 `beat`). 장면마다 압축률이 다르면 박자가 휘어 곡이 깨진다.

⚠ **`end` 는 `full`(5.8) 이 `base`(5.4) 보다 길다.** 큐 축에서 `end` 바로 뒤가 `names`(62.2) 라 `base` 를 못 늘린다 —
대신 `full` 을 늘렸고, 그러면 그 장면만 7% 느리게 흐른다(로고 리빌은 오히려 그게 낫다). **짧게 만드는 것과 달리 길게는 안 깨진다.**
그 0.7초는 그림뿐인 장면(`map`·`stairs`·`kosdaq`)에서 빼 왔다 — **총 길이는 59.0/45.0 그대로다**(규정 상한 1분).

## 실사·3D 는 «영상»으로 들어간다 — webm(VP9)이어야 한다

`found`(본사 항공) · `end`(본사 로우앵글) · `reveal`(3D 컷어웨이) 은 `<video>` 를 깔고 그 위에 글자를 얹는다.

- ⚠ **오픈소스 Chromium 은 H.264 를 못 읽는다.** mp4 를 그대로 걸면 `MediaError code 4` 로 **조용히 빈 화면**이 된다.
  그래서 렌더가 실제로 무는 것은 `footage/*.webm`(VP9)이고, mp4 는 편집용 마스터로만 둔다(저장소에는 안 올린다).
- ⚠ **`window.seek(t)` 가 이제 Promise 를 돌려준다.** `video.currentTime` 은 비동기라 `seeked` 를 안 기다리면
  캡처가 «직전 프레임»을 찍는다 — 같은 t 를 두 번 찍었을 때 다른 그림이 나오고, 그러면 이 파이프라인의 전제가 깨진다.
  `par.cjs`·`preview.cjs` 는 `window.ready` 로 첫 프레임 디코드까지 기다린 뒤 시작한다(못 읽으면 렌더가 시끄럽게 죽는다).
- **영상을 못 읽는 환경에서는 «원래 그림»이 그대로 선다**(`vok()`). 실사 레이어의 불투명도를 0 으로 두어
  아래의 SVG 일러스트가 보이게 한다 — 빈 화면으로 두지 않는다.
- 실사는 1322×748 유튜브 화면 녹화라 1080p 로 1.45배 업스케일했다. 옛 캐노피 문구(`Passion for Success`)가
  **현행 슬로건이 아니므로**, 그 글자가 안 보이는 두 컷(항공 7.45s~ · 로우앵글 2.45s~)만 골랐다.

```bash
# 실사 그레이딩(마스터 mp4 → 렌더용 webm). 어둡게·파랗게 맞추지 않으면 그 컷만 튄다
GRADE="scale=1920:1080:flags=lanczos,unsharp=5:5:0.45:5:5:0.0,\
curves=r='0/0.02 0.5/0.38 1/0.86':g='0/0.03 0.5/0.42 1/0.90':b='0/0.09 0.5/0.52 1/1.0',\
eq=contrast=1.12:saturation=0.72:brightness=-0.06,vignette=PI/4.2,noise=alls=6:allf=t+u"
ffmpeg -ss 7.45 -t 4.6 -i <원본> -vf "$GRADE" -an -c:v libx264 -crf 16 footage/hq_aerial.mp4
ffmpeg -i footage/hq_aerial.mp4 -c:v libvpx-vp9 -crf 26 -b:v 0 -an footage/hq_aerial.webm
```

## 밋밋한 장면 뒤에 «흐린 배경»을 깐다 (`bgSeek`)

글자·그래픽만 있는 장면은 배경이 통째로 비어 완성도가 떨어져 보였다.
**새 소재를 만들지 않는다 — 이미 가진 실사·3D 컷·사진을 흐리게 재사용한다.**

| 장면 | 뒤에 깐 것 | 진하기 | 왜 그것인가 |
|---|---|--:|---|
| hook | `scrubber3d.webm` | 0.40 | 팹 컷어웨이 — 흐리면 «현장»으로 읽힌다 |
| kosdaq | `photos/oldhq.jpg` | 0.46 | **2006 상장 때는 구사옥이었다** |
| stairs | `photos/bg-trophy.jpg` | 0.42 | **수출의 탑 트로피가 실제로 그 사진 안에 있다** |
| future | `photos/bg-lab.jpg` | 0.42 | ⚠ **지금은 3D 컷이 덮는다** — 클립을 못 읽을 때만 보이는 폴백이다 |
| close | `hq_lowangle.webm` | 0.38 | 바로 뒤 `end` 가 **같은 컷을 선명하게** 쓴다 — 흐림이 풀리는 연결 |

- ⚠ **흐림은 «작은 판»(480×270)에 걸고 4배로 키운다.** 1920 폭에 `filter:blur()` 를 직접 걸면
  프레임당 비용이 커져 렌더가 눈에 띄게 느려진다. 어차피 흐린 그림이라 화질 손해가 없다.
- ⚠ **사진 배경은 `vok()` 로 판정하면 안 된다.** video 가 없으므로 언제나 거짓이 되어 통째로 안 뜬다 —
  `img.naturalWidth` 로 «실제로 실렸는지»를 본다. 못 읽으면 `opacity` 0 으로 남아 원래 화면 그대로다.
- ⚠ **딱 떨어지게 켜고 끄면 «깜빡» 하고 보인다.** 장면 안에서 서서히 들고 나야 배경으로 읽힌다.
- ⚠ **너무 옅으면 «있는지 없는지» 모른다.** 첫 판(0.26~0.34)은 렌더해 보니 거의 안 보였다.
  가운데 띠 스크림도 같이 눅였다(.62 → .50).

## 사진 자산 (`photos/`) — 공개 저장소에 넣기 전에 세 가지를 한다

사용자가 홍보영상 캡처로 보내 준 것들이다. **그대로 커밋하지 않는다.**

1. **워터마크·흰 액자는 «잘라서» 없앤다.** 우하단 마크는 60×50px 라 그 구석을 잘라내면 끝이다 —
   지우개로 덮으면 자국이 남고, 배경으로 흐리게 깔 자료라 몇 %를 잘라도 화면에서 손해가 없다.
2. **사람이 있으면 저장본 자체를 익명화한다.** 「화면에서는 흐려서 안 보인다」는 부족하다 —
   저장소에 남는 파일이 원본이면 그게 공개되는 것이다. 랩실은 900px 로 줄이고 흐림을 구워 저장했다
   (그 크기에서 얼굴은 7px 이라 복원이 원리적으로 불가능하다).
3. **차량 번호판·명패를 확대해 확인한다.** 구사옥 사진은 뒷면 20px 라 판독 불가를 눈으로 확인했다.

⚠ **«GST 것인지»를 먼저 본다.** 받아 둔 영상 중 하나는 ASML 로고가 박힌 장비 일러스트였고,
다른 하나는 **UNITECH 로고 리빌로 끝나는 타사 홍보영상**이었다. 사내 공모전 출품작에 타사 영상이
들어가면 그건 사고다 — 쓰기 전에 끝까지 훑어본다.

## 디졸브가 홀드를 먹는다 — 홀드는 «디졸브 + 읽을 시간»이다 (v18 · 사용자 재지적)

v14 에서 홀드를 줬는데도 「라인스톱에서 넘어갈 때 부자연스럽다」가 다시 왔다. 원인은 산수였다:
장면 디졸브(0.32초)가 홀드 «끝»에서 시작하므로, 홀드 0.4초 중 스탬프가 온전히 서 있는 시간은
0.1초뿐이었다. **홀드를 정할 때는 디졸브 몫을 먼저 떼고 계산한다** — sf6 0.6 · stop 0.4+연장분.
회수는 그림 위주 장면에서: s6 −0.2(1.03배속, 지각 불가) · reveal −0.2 · found −0.2 · map −0.3 · close −0.2.

코스닥은 2박자가 됐다(사용자 요청 — 2026 시총 1조): 초록 선(2006 상장 ▲34.5%)이 서고,
금색 선이 이어받아 치솟아 「시가총액 1조」에 닿는다. 한 선이 «계속 올라온 20년»으로 읽힌다.
소리도 2박이다: 상장 벨 → 올라가는 블립 셋 + 라이저 → 심벌+큰 벨. 수출의 탑(금색 꺾은선)과
같은 어휘라 «성장 장면 = 금색 선» 규약이 생겼다.

## 인트로는 «페이크아웃»이다 — 기념 문구를 띄우고 화면을 꺼버린다 (v16~17 · 사용자 아이디어)

**순서는 «카드 먼저»다(v17 · 사용자 지시).** 어둠 → 연표·제목·기념 문구(조용한 공식 카드) →
험이 뚝 끊기며 꺼짐(붕괴→선→점) → **CRT 발버둥**(흰 번쩍·슬릿·워시 — 옛 «켜짐» 재료 재사용) →
어둠 → 훅의 타자기. 켜짐 재료를 앞에 두면 말 없이 1.8초를 먹는다 — 뒤로 보내면
«죽은 신호가 버둥대는 그림»이 되어 같은 재료가 두 배 일을 한다.

사용자: 「먼저 창립 25주년 문구가 나오고 화면이 꺼지는 CRT가 나오는 것은 어떨까?」 — 채택했다.
공식 기념영상처럼 시작해 놓고 영상 스스로 그 대본을 «꺼버리는» 구조라, 이 영화의 반전
(아무 일도 안 일어났습니다)과 정확히 같은 종류의 농담이다.

- **문구는 훅과 «거울»로 짰다.** 인트로 「지난 25년, **참 많은 일이 있었습니다.**」 → *뚝* →
  훅 「지난 25년, GST에는 **아무 일도 안 일어났습니다.**」 같은 어절로 시작해 반대로 끝난다 —
  병렬 구문이라 반전이 저절로 선다. 마지막 pivot(「…꽤 많은 일을 했습니다」)이 원을 닫는다.
- **꺼짐 = 세로 붕괴 → 흰 가로선 → 점 → 소멸**(CRT 관용구). 훅의 배경이 검정이라
  꺼짐-어둠-타자 연결이 이음매 없이 붙는다.
- **소리가 절반이다.** v15 전까지 인트로 4초는 «완전 무음»이었다 — 밋밋함의 실제 원인.
  전원 펑 → 진공관 험 → 깜빡임 틱 → 연표 두 음(880→1174Hz, «그때→지금») → 제목 착지 벨 →
  꺼질 때 **험이 뚝 끊긴다.** 소리가 죽어야 화면이 죽은 걸로 믿는다.
- ⚠ **표시(4.3s)가 큐 축(base 4.0)보다 길다.** base 를 4.3 으로 늘리면 s6 의 큐(70.0)와 겹쳐
  만담 소리가 인트로로 잘못 매핑된다 — `end`(5.8/5.4)와 같은 수법으로 full 만 늘렸다.
  그래서 **bgm 큐 = 66 + 영상시각/1.075** 로 환산해 적는다(bgm.cjs 주석 참조).
- 연표는 «2001 먼저, 0.35초 뒤 -2026 이 RGB 분리와 함께」 붙는다 — 글자 없이 «그때→지금»이
  생긴다. 글리프는 프레임에 있던 것을 가렸다 여는 것뿐이라 폰트 위험이 0이다.
- 정지 꼬리에는 숨(제목 글로우 0.955~1.0 호흡 · 밀어들어가기 1.000→1.012 · f95 마이크로 글리치).
  ⚠ 호흡은 **어두워지는 쪽으로만** — 밝히면 255 에서 클리핑돼 글로우가 «머리가 깎인» 모양이 된다.

## 컷의 마지막 프레임은 «홀드»가 지킨다 (v14 · 사용자 지적)

사용자: 「라인스톱 씬에서 없었습니다 훅 짤린 것 같고」 — 실측으로 두 겹의 문제였다.

1. **컷이 스탬프가 뜨자마자 끝났다.** ctx 리와인드 컷(sf6·stop)은 표시 길이 = 클립 길이(1.8초)라
   홀드가 0이었다. → `cutScene` 의 `clipDur` 인자를 «표시 길이»로 주면 클립은 1배속으로 끝까지
   돌고 `vseek` 클램프(duration−0.05)가 마지막 프레임을 남는 시간만큼 정지시킨다.
   sf6 1.8→2.1 · stop 1.8→2.2 · future 3.9→4.3. **timeline 의 cue0·base 는 안 건드린다.**
2. **S4 는 스탬프가 «마지막 1프레임(f53)»에만, 그것도 등장 도중(α≈0.69)에 있었다.**
   클램프가 d−0.05 = f52 를 보므로 스탬프는 **원리적으로 안 보였다.** 홀드만 늘려도 반투명
   스탬프가 얼어붙는다. → f52(배경)·f53(혼합)에서 α 를 역산해 «착지한» 스탬프를 복원하고
   (`true = bg + (obs−bg)/α`), 그 프레임 12장을 붙여 **클립 자체를 2.2초로 연장**했다.
   ⚠ S1·S2·S3 은 스탬프가 일찍 착지해 손대지 않았다 — 컷마다 끝 프레임을 «재서» 판정한다.

같이 고친 것: 장면 디졸브 0.22→0.32초(「살짝만 자연스럽게」) · 수출의 탑을 계단 막대에서
**치솟는 꺾은선+화살촉**으로(2.4초로 압축, 남는 시간은 액침냉각 홀드에) · 액침냉각→마무리
BGM 다리 — 공로(lead) 장면이 빠진 뒤 옛 47.0~52.2 큐들이 죽은 구간에서 0.3초로 접혀
«잡음 같은 붕 소리»가 됐었다(전환이 어색하던 실제 원인). 그 큐들을 걷어내고, 미래 패드를
마무리 첫 박까지 끌고 가 겹치게 하고(겹침이 곧 「이어지는 느낌」이다), 현(E·G)을 경계
너머로 걸쳤다. 꺾은선의 발걸음 5방·팡파르도 새 타이밍으로 옮겼다 — 그림과 소리는 한 표다.
⚠ 꺾은선 상수(`TR_P`·`TR_CUM`)는 **모듈 스코프**다 — 빌더 IIFE 안에 두면 `SCN.stairs` 가
매 프레임 ReferenceError 를 낸다(엔딩 `PARTS` 때 겪은 그 함정, 실제로 한 번 더 밟았다).

## 과거형 훅(「없었습니다.」)은 네 번으로 닫는다 (v13 · 사용자 지적)

「없었습니다.」 금색 스탬프는 **실란·SF₆·칠러·라인정지 네 장면의 닫힌 세트**다. 두 곳에서 그 규칙이 깨져 있었다.

**① 인트로의 `> NO INCIDENT DETECTED`** — 「GST 창립 25주년」 **4픽셀** 아래에 붙어 있었다
(위 간격은 130px). 사용자가 「뭔 글씬지도 모르겠다」고 한 것이 이것이다. 간격만 벌려도 안 되는 이유 셋:
- **훅의 반전을 먼저 말해 버린다.** 바로 다음 장면이 「지난 25년, GST에는 아무 일도 안 일어났습니다」를
  타자기로 찍는다 — 그게 반전인데, 1.5초 앞에서 같은 말을 영어로 먼저 하면 훅이 «되풀이»가 된다.
- **영어 전용인데 읽을 시간이 없다.** 19px 모노 영문 22자 · 1.5초 · 폰. 안 읽히는 글자는 잡음이다.
- 모노 두 줄이 제목을 위아래로 감싸는 구성 자체가 과하다.
→ 아래 줄을 지우고 윗줄도 `2001-2026` 만 남겨 가운데로 옮겼다. **글자를 새로 조판하지 않는다** —
  기존 낱말 덩어리(`SIGNAL`·`RESTORED`·`—`·`2001-2026`)에서 연표만 오려 130px 평행이동했다.
  구도는 그대로다(남는 블록 중심 y543 = 1080의 정중앙).

**② 액침냉각 클립의 「없었습니다.」** — 이건 **못 지킬 말**이다. 액침냉각은 아직 시범 단계라
「없었다」고 말할 실적이 없다. 게다가 3초 뒤 마무리(「아무 일도 없게 하는 것…」)의 자리를 뺏는다.
- 「없게 하겠습니다」는 **목적어가 없어 어색하다**(사용자 지적). 「시작됩니다」·「가능해집니다」도
  기술 이름을 안 알려 준다 — 이 클립은 **한국어로 액침냉각을 한 번도 안 부른다**. 파란 수조만 보고
  그게 뭔지 아는 사람은 많지 않다.
→ 금색 상자는 두고 **안쪽 글자만 「액침냉각」으로** 갈았다. 이름표는 주장이 아니라 사실이라 시제
  문제가 없고, 금색 스탬프의 시각 모티프는 남아 「과거 4연타 → 미래 1장」으로 읽힌다.
- ⚠ **상자를 «지우면» 안 된다.** 실측상 그 밑 배경이 계속 움직인다(x 215~414 에서 프레임당 1만 픽셀).
  다른 프레임을 갖다 붙이면 그 자리가 어긋난다. 상자를 두고 안쪽만 칠하면 배경을 한 픽셀도 안 건드린다.
- ⚠ **닫기 연산으로는 옛 글자가 안 지워진다**(획이 10px 넘는다 — 실제로 두 글자가 겹쳐 나왔다).
  둥근 «직사각형»이므로 행마다 «첫 금색 ~ 끝 금색»을 통째로 채운다.
- ⚠ **금색을 상수로 적지 않는다.** 「그 프레임 그 행의 금색 중앙값」으로 칠하면 상자가 커지며 등장하는
  0.87초 동안의 밝기 변화까지 저절로 따라온다. 글자 크기도 프레임마다 상자 폭에 비례시킨다.
- 영문 꼬리말의 `— It didn't happen.` 도 같은 이유로 뗐다(얇은 띠라 세로 선형보간으로 지운다).

**공통 규율 — 남의 컷을 고칠 때.** 배경이 정지인 얇은 띠는 «세로 선형보간»으로 지우고, 배경이
움직이는 넓은 면은 «지우지 말고 덮는다». 그리고 **시작 프레임을 손으로 적지 않는다** —
인트로에서 55를 57로 잡아 두 프레임에 옛 글자가 그대로 남았다. 프레임마다 재서 판정한다.

## 3D 만담 (`3d/s6.html`) — 설비를 «캐릭터»로 세운다

첫 판은 흰 상자 둘이 빈 바닥에 멀찍이 서 있고 말풍선만 떠서, 사용자가 **「너무 허접해 보인다」**고 했다.
고친 것은 셋이고, **셋이 동시에 있어야 «캐릭터»로 읽힌다** — 하나만 해도 여전히 상자다.

1. **얼굴.** HMI 패널(`makeFace`)에 눈·눈썹·입을 그린다. 깜빡이고, 서로를 쳐다보고, 말할 때 입이 움직이고,
   펀치라인에서 웃는다(`^^` 아치). 상태는 전부 인자로 받는다 — 함수 안에 시간이 없어야 `seek(t)` 가 순수해진다.
2. **움직임.** 피벗 그룹을 «발밑»에 두고 기울인다(몸통 중심에 걸면 기계가 떠 보인다).
   idle 은 숨쉬듯 오르내리고, 말할 때는 상대 쪽으로 기울며 **음절 포락선(`syl`)으로 끄덕인다** —
   입과 끄덕임이 같은 파형을 써야 입만 따로 놀지 않는다.
3. **구도.** 빈 바닥이 «허접함»의 절반이었다. 뒤에 서브팹(파이프랙·케이블 트레이·원경 캐비닛)을 세우고
   먼지·광선을 깔았다. 카메라도 당겨 **두 기계가 화면을 채운다**.
   · 케이블 트레이는 **y 4.3 위**로 올린다 — 첫 판은 3.05 라 두 얼굴 «뒤»를 가로질러 화면이 어수선했다.

⚠ **말풍선은 머리 «위»가 아니라 «옆»에 단다.** 위에 달면 카메라를 빼야 해서 기계가 작아지거나 풍선이 화면 밖으로 나간다.
폭은 글자에 맞춰 잘라내고 `Sprite.center` 로 **꼬리 쪽 끝**을 앵커로 삼는다(폭이 변해도 위치가 안 흔들린다).
줄바꿈은 **카피에 직접 적는다** — 자동 줄바꿈에 맡기면 「…25년째 그 / 대답이야.」 처럼 어색한 자리에서 끊긴다.
⚠ 꼬리 끝은 «기계 몸통 위»다. 바깥으로 빼면 말풍선이 잘린다(실측: 첫 판이 화면 밖으로 나갔다).
⚠ 카메라 push 를 키우면 **끝에서** 말풍선이 잘린다 — 가까워질수록 풍선이 프레임 대비 커지기 때문이다.

**대사는 「아무 일도 없었다」를 «자랑»으로 뒤집는 자리다**(영상 전체의 주제 그대로).
소리도 같이 붙였다 — `bgm.cjs` 의 큐 축 70.0~76.4 가 말풍선이 뜨는 시각(`BEATS.on + 70.0`)과 «같은 표»를 본다.
대사가 소리 없이 지나가면 코미디가 안 산다.

## 3D 팹 단면 (`3d/scene3d.html`)

ASML 홍보영상의 «장비가 비치며 라벨이 따라붙는» 구간을 참고했다. 앞부분의 포토리얼 CGI 는
수억 원짜리 프로덕션이라 흉내 낼 수 없지만, **이 구간은 Three.js + 헤들리스 Chromium(SwiftShader)으로 된다.**

### ⚠ 배치는 «지어내지 않는다» — 실제 팹 구조다

사용자가 준 `gst-equipment-3d.html` 이 정본이다.

| 층 | 무엇이 있나 |
|---|---|
| **클린룸 데크** (y=2.9, 기둥 위 슬래브) | 공정 장비(고객 팹의 메인 툴) · **칠러** |
| **서브팹** (y=0, 그 아래) | **스크러버** · 진공펌프 |

- **배기**: 공정 장비 아래 → 데크의 «서비스 틈»으로 라이저 하강 → 진공펌프 → 스크러버 **옆구리** 유입
- **냉각수**: 칠러 ↔ 공정 장비 (공급 파랑 · 회수 빨강)
- ⚠ **예전 버전은 스크러버와 칠러를 같은 바닥에 나란히 뒀다 — 틀린 그림이었다.** 칠러는 클린룸에서
  공정 장비를 식히고, 스크러버는 서브팹에서 그 배기를 받는다. 둘은 «같은 줄에 선 제품 두 개»가 아니다.
- ⚠ **배기를 스크러버 «위»(버너 뭉치)로 넣지 않는다.** 위는 배출구다 — 거꾸로 그리면 아는 사람이 바로 안다.
- 외형도 실물을 따른다: 스크러버는 캐비닛 + 위 버너 뭉치(배관 5개) + 신호탑 + 측면 루버(GAIA 계열),
  칠러는 루버·경사 상판(EES 계열).

```bash
cd shortform && python3 -m http.server 8742 --bind 127.0.0.1 &   # ES 모듈은 file:// 에서 안 뜬다
cd 3d && npm i three && FPS=30 OUT=f3d node shoot.cjs            # 138프레임 · 약 1.3분
ffmpeg -framerate 30 -i f3d/f_%04d.png -c:v libvpx-vp9 -crf 24 -b:v 0 -an ../footage/scrubber3d.webm
```

- ⚠ **전체를 3D 로 만들지 않는다.** 소프트웨어 래스터라이저라 프레임당 0.5~0.7초다(리드백이 병목).
  59초 전체면 고칠 때마다 35~105분이 든다 — **핵심 한 컷만 3D**가 실무적인 선이다.
- ⚠ **팔레트를 영상에 맞춘다.** «흰 클린룸»으로 만들면 그 4초만 다른 영상처럼 튄다 —
  배경은 영상과 같은 짙은 남색이고 설비만 밝다. 빈 바닥에 조명이 고이면 «조명 누수»로 보이므로
  안개를 당겨(11~27) 먼 바닥을 배경색으로 죽인다.
- ⚠ **사람 실루엣을 세운다.** 크기를 견줄 것이 없으면 설비가 장난감으로 보인다 — POC 에서 이것이 제일 컸다.
- ⚠ **라벨은 화면 «오른쪽»에만 둔다.** 왼쪽은 본편 카피가 쓰는 자리다. 실제로 두 번 겹쳤다 —
  「유해가스 유입」이 머리글 줄에, 「스크러버」가 「219,000시간」 줄에. **4초에 사람이 읽을 수 있는 라벨은 넷이 한계**다.
  화면에서 실제로 뽑아 보고 정하는 수밖에 없다(좌표로는 예측이 안 된다).
- ⚠ **Three.js 의 `position`·`rotation`·`scale` 은 읽기전용 접근자다.** `Object.assign(mesh,{position:…})` 은
  모듈(strict)에서 던진다 — `.position.set()` 을 쓴다.
- 카메라는 피사체를 잡되 **시선만 왼쪽으로 튼다**(시프트 렌즈와 같은 원리). 목표점을 옮기면 각도가 같이 변해
  구도가 무너진다.
- `node_modules` 는 저장소에 없다(`npm i three`). 렌더에 실제로 필요한 것은 결과물 `footage/scrubber3d.webm` 뿐이라,
  three.js 가 없어도 본편 렌더는 그대로 된다.

| 59.30 | **임팩트** — 흰 섬광 · 아나모픽 바 · 소나 링 · 불티 · 락업 펀치 |
| 59.40–60.06 | **파티클이 «실제 CI 모양»으로 날아와 꽂힌다** |

| 60.34–61.85 | `GST GROUP` · 2001 · 창립 25주년 · 2026 · **Build Up GST** · 계열 3사 |

**순서가 규약이다.** 「다음 25년도, 아무 일 없이.」(컨셉의 펀치라인) → 브랜드 서명.
⚠ **슬로건이 펀치라인을 밀어내면 영상 전체의 농담이 죽는다.**

- ⭐ **파티클의 «도착점»은 실제 로고의 알파에서 뽑는다**(`buildLogoPts`). 지어낸 도형으로 모이면 그건 다른 로고다.
  로고 파일을 못 읽으면 `LOGO_PTS` 가 비고, 그때는 조립 없이 글자 폴백이 그냥 뜬다(빈 화면으로 두지 않는다).
- ⚠ **`file://` 에서는 캔버스가 «오염»돼 `getImageData` 가 SecurityError 로 막힌다.** 그래서 `par.cjs`·`preview.cjs`
  가 **자체 http 서버**(`serve.cjs`)로 띄운다. 외부 프로세스를 쓰면 포트·정리가 또 하나의 실패 지점이 된다.
- ⚠ **전부 «t 의 순수함수»여야 한다.** 참고본은 프레임마다 z 를 적분하고 `Math.random()` 으로 흔드는데,
  그러면 같은 t 를 두 번 찍었을 때 다른 그림이 나와 이 파이프라인의 전제가 깨진다 →
  속도의 **누적 거리를 표로 미리 구해 두고**(`SCUM`) z 를 되감고, 흔들림은 **씨앗 위상의 sin** 으로 만든다.
  불티·소나 링도 닫힌 식이다. 실제 브라우저로 되풀이 대조해 확인했다.
- ⚠ **창립은 2001.10.01 이다.** 참고본의 타임라인은 `1999`인데 그건 GST 의 해가 아니다 —
  참고본에서 가져올 것은 **생김새**이지 숫자가 아니다.
- ⚠ **흰 섬광은 «짧고 세게»가 전부다.** 선형으로 내리면 화면이 여러 프레임 하얗게 떠 있는다
  (참고본의 곡선 그대로 6%에 정점 → 30%에 .22 → 0).
- ⚠ **샤인은 `mix-blend-mode:screen` 이라 조금만 진해도 «흰 판»으로 읽힌다.** 알파를 낮추고 넓게·흐리게.
- 색종이는 이 톤과 안 맞아 뺐다(빌더도 같이 걷어냈다 — `#confetti` 가 없는데 빌더가 남으면 null 로 죽는다).
- 계열 3사 이름은 36px 이다. 52px 이면 메인 로고와 위계가 다툰다 — 참고본의 위계는 «로고만 크고 나머지는 작다».

## 왜 이런 문구·색인가

- **스탬프는 네 번 모두 「없었습니다.」로 같다.** 반복 개그는 «똑같은 말»이 반복될 때 가장 세고,
  글자가 짧아야 강당 뒤쪽에서 읽힌다(62px → 84px). 네 장면 모두 화면의 «같은 자리»(1180, 400)에 찍힌다 —
  자리가 흔들리면 리듬이 죽는다. 그리고 마지막 「아무 일도 없게 하는 것」과 정확히 맞물린다.
- **골드는 스탬프 전용이다.** 글자 강조는 CI 파랑 계열(#8fc0ff)로 옮겼다. 남색+골드는 기업 영상에서 가장 흔한
  조합이라 «템플릿 같다»로 읽힌다. 색을 하나로 좁히면 스탬프가 화면에서 유일한 노란 점이 되어 더 튄다.
  다만 «물체»의 금색(1억불 막대·트로피·지도 핀·색종이)은 그대로 둔다 — 그건 색 강조가 아니라 사물이다.
- **제품 이름 장면(`names`)이 이 영상에서 가장 «우리 것»이다.** GAIA(대지) · GARAM(가람, 강) · SOOPIA(숲) ·
  AQUA(물) — 독가스를 태우는 기계에 붙은 이름이 전부 자연이라는 사실은 제품 목록을 들여다본 사람만 알 수 있다.
  검색이나 생성형 AI 로는 나오지 않는 재료라, 같은 컨셉이 겹칠 위험을 가장 크게 줄여 준다.
  ⚠ 이름의 «뜻»(대지·강·숲·물)은 공식 설명이 아니라 읽어 낸 것이다. 사내에 공식 유래가 있으면 그것을 따른다.
  라인업이 바뀌었을 수 있으니 제품 목록도 함께 확인할 것.

### ⚠ 사진은 «회사 자산»에서 가져온다 — 기사 사진은 쓸 수 없다

- **언론 기사의 사진은 언론사·사진기자의 저작물이다.** 사내 상영이라도 무단 사용이고, SNS 에 올리는 순간
  홍보물이 된다. 공모전에서 **확인된 유일한 «수상 취소» 사유가 저작권**이다.
- **쓸 수 있는 것**: 회사 홈페이지·IR 자료·사업보고서·사보의 사진, 홍보팀 아카이브, 전시회(세미콘 등) 부스 촬영본,
  본인이 직접 찍은 사진.
- ⚠ **고객사 팹 내부·설비 사진은 보안·NDA 대상일 수 있다.** 반드시 사내 확인 후 쓴다.
- 인물이 찍힌 사진은 본인 동의를 받는다. 퇴직자가 포함되면 특히 확인이 필요하다.

### 로고 변환은 `make-logo.py` 한 곳이다

```
python3 make-logo.py gst.png                                   # GST (기본 — 예전 동작 그대로)
python3 make-logo.py est.png  --name est  --policy keep --drop-last-band
python3 make-logo.py robo.png --name robocare --policy mono
python3 make-logo.py gst.png  --name gst-mark --policy gst --drop-last-band   # 엔딩 마크 슬롯용
```

흰 바탕에 찍힌 로고는 «관측 = 잉크×a + 흰색×(1−a)» 이므로 `a = 1 − min(채널)/255` 로 잉크 커버리지를
구하고 원색을 역산한다. **임계값으로 자르지 않는다** — 가장자리 안티에일리어싱이 계단이 된다.
**투명 PNG 가 아니어도 된다**(흰 바탕이면 JPG 로 충분하다). 투명 PNG 는 흰색에 합성해 먹인다.

| policy | 쓰는 곳 | 하는 일 |
|---|---|---|
| `gst` | GST | 밝은 파랑 마크를 CI 파랑으로 고정, 나머지는 흰색 |
| `keep` | EST | **유채색 마크는 색을 남기고**(가장 밝은 채널이 235 가 되게 올린다) 무채색 잉크만 흰색으로 |
| `mono` | ROBOCARE | 흑백 워드마크 — 어두운 배경에서 옳은 반전은 «전부 흰색» 하나뿐이다 |

⚠ **계열사마다 스크립트를 복사하지 말 것**(제2원칙). 새 로고는 «정책을 고르는 것»이지 코드를 새로 쓰는 게 아니다.

⚠ **`--drop-last-band`(태그라인 떼기)는 두 번 틀렸다. 둘 다 «태그라인이 심볼과 x 로 겹치는» 자리다.**
44px 슬롯에서는 태그라인이 읽히지 않는 얼룩이라 반드시 떼야 한다.
- **세로 빈 칸은 «위쪽 60%»에서 찾는다.** 전 높이로 보면 태그라인이 심볼과 글자 사이의 빈 칸을 메운다 —
  GST 는 그 틈이 5px 로 줄어 문턱(7px)에 못 미쳐 `split=0` 이 나왔고, 태그라인이 통째로 남았다.
- **지우는 경계는 «그 띠 안에서» 다시 찾는다.** 위쪽 행에서 잰 경계로 지우면 심볼의 아래 꼭지와
  x 가 겹치는 앞글자가 살아남는다 — GST 는 「Globa」 다섯 글자가 그렇게 남았다.
  띠 안에서 보면 «심볼 꼬리 → 빈 칸 → 태그라인» 이 그대로 드러난다.

⚠ **`logos/gst-white.png` 는 배포된 이름이라 바꾸지 않는다**(엔딩의 큰 로고 리빌이 그 경로를 문다).
엔딩 아래쪽 계열 3사 마크는 태그라인을 뗀 `gst-mark.png` 를 따로 쓴다 — 같은 로고를 크기에 따라
다르게 쓰는 것이지, 둘 중 하나가 틀린 게 아니다.

## 다시 만들기

```bash
cd shortform
./fetch-fonts.sh            # Noto Sans KR 400/700/900 · Black Han Sans → fonts/ (약 20MB, 저장소에 없음)
./render.sh                 # 제출본 59초
MODE=short ./render.sh      # 짧은 버전 45초
SS=1 ./render.sh            # 모션블러 끄고 3배 빠르게(미리보기용)
```

필요한 것: node 18+ 와 `playwright` 패키지(+ chromium), ffmpeg(libx264·aac). 시스템에 컬러 이모지 폰트가 있어야
🌵🔥🌍🏆❄️ 가 그려진다. 렌더 시간은 4코어 기준 59초본 약 13분(SS=3) / 4분(SS=1).

- **모든 움직임은 `window.seek(t)` 하나의 순수함수다.** 어느 프레임을 몇 번 찍어도 같은 그림이 나온다.
- **`timeline.js` 가 두 버전의 정본이다.** 장면 길이·삭제는 여기서만 고친다 —
  `scene.html` 도 `bgm.cjs` 도 이 표를 읽으므로 그림과 소리가 갈리지 않는다.
- **모션블러는 «3배로 찍어 평균»이다**(SS=3 → 90fps 캡처 → `tmix=frames=3` → 30fps).
  굴러가는 풀·웨이퍼·색종이가 끊겨 보이지 않게 하는 유일한 방법이다.
- **오디오는 -16 LUFS 로 정규화**하고 48kHz 로 고정한다(PowerPoint·구형 플레이어 호환).
- 렌더가 끝나면 `*_poster.png` 도 같이 나온다 — 상영 목록·제출 메일용 대표 이미지다(첫 프레임은 페이드인이라 검다).
- 문구를 고치려면 `scene.html` 의 해당 `<section>` 만 고치면 된다. 영어 소자막은 `.en`.

## 나레이션 — 얹으면 웃음이 배가 된다

담담하고 건조하게, 다큐 나레이션처럼 읽는다. **절대 신나게 읽지 않는다.** 휴대폰 음성메모로 충분하다
(조용한 방, 입에서 15cm, 한 문장씩 끊어 읽고 문장 사이 1초 쉬기).

> 지난 25년, GST에는 아무 일도 안 일어났습니다. 정말, 아무 일도.
> 예를 들면, 실란 가스는 공기와 닿는 순간 스스로 불이 붙습니다. — 안 붙었습니다.
> SF₆ 가스는 대기에 3,200년을 머무릅니다. — 안 남았습니다.
> 식각 공정은 온도가 0.1도만 흔들려도 웨이퍼가 상합니다. — 안 흔들렸습니다.
> 반도체 공장이 멈추면 웨이퍼 수만 장을 버립니다. — 안 멈췄습니다.
> 이 모든 «아무 일»의 뒤에는, 스크러버와 칠러가 있었습니다. 365일 24시간, 25년. 약 21만 9천 시간.
> 아무 일도 안 일어나게 하려고, 우리는 꽤 많은 일을 했습니다.
> 2001년 10월 1일, 퇴직금 500만원. 일본이 독점하던 스크러버를 우리 손으로.
> 2006년, 코스닥 상장. 첫날 34.5%. 화성에서, 여섯 나라로. 그리고 창립 20주년, 1억불 수출의 탑.
> 그리고 다음 25년은, 이미 시작됐습니다. 이번엔 AI 데이터센터의 열을 — 액침냉각.
> 그 길을 정하고, 먼저 걸어 주신 분들. 그리고, 함께 걸어온 모든 임직원.
> 그래서 오늘도, 아무 일도 없습니다. 아무 일도 없게 하는 것 — 그게 우리가 25년 동안 한 일입니다.
> GST 창립 25주년. GST, EST, 로보케어. 다음 25년도, 아무 일 없이.

녹음 파일(`voice.wav`)을 받으면 BGM 을 자동으로 낮춰(ducking) 섞는다:

```bash
FF=$(python3 -c "import imageio_ffmpeg as f; print(f.get_ffmpeg_exe())")
$FF -y -i GST_25th_nothing_happened.mp4 -i voice.wav \
  -filter_complex "[0:a][1:a]sidechaincompress=threshold=0.06:ratio=8:attack=20:release=350[d];[d][1:a]amix=inputs=2:duration=first:weights=1 1.6[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 48000 GST_25th_with_voice.mp4
```
