# GST 창립 25주년 숏폼 샘플 — «아무 일도 안 일어난 25년»

`GST_25th_nothing_happened.mp4` · 56초 · 1920×1080 · 30fps · H.264 + AAC · 가로형.
실사·사진·유명 음원 없이 **HTML/CSS/SVG 모션그래픽을 프레임 단위로 캡처**해 만들었고, BGM·효과음은
브라우저(OfflineAudioContext)로 합성했다. 저작권 자산이 하나도 없다 — 폰트는 Google Fonts(OFL).

## 컨셉

「지난 25년, GST에는 아무 일도 안 일어났습니다.」로 시작하는 반전 서사.
실란은 안 붙었고, SF₆는 안 남았고, 공장은 안 멈췄다 → 그 «아무 일»의 뒤에 스크러버가 있었다 →
아무 일도 안 일어나게 하려고 꽤 많은 일을 했다(2001 창업 · 2006 코스닥 · 여섯 나라 · 수출의 탑) →
「아무 일도 없게 하는 것. 그게 우리가 25년 동안 한 일입니다.」 → 「다음 25년도, 아무 일 없이.」

패러디는 없다. 웃음은 «담담한 반전»(귀뚜라미·굴러가는 풀·노란 스탬프)에서, 뭉클함은 마지막 10초에서 온다.
규정대로 영상 안에 팀명·제출자명은 없다.

## 사실 근거(전부 공개 자료 · 확인된 것만 화면에 썼다)

- 2001-10-01 설립, 창업자가 퇴직금 500만원으로 시작, 일본이 독점하던 스크러버 국산화 — 한국경제 2019·2024, 사업보고서
- 2006-02-01 코스닥 상장, 공모가 5,800원·시초가 7,800원(+34.5%) — 이투데이
- 해외 법인: 미국 2006 · 시안 2013 · 대만·우시 2016 · 허페이 2017 · 우한 2019 · 싱가포르 2020 · 유럽·일본 2024 — 사업보고서·회사 연혁
- 수출의 탑: 5백만불(2007) · 1천만불(2011) · 2천만불(2014) · 3천만불(2019) · 1억불(2021) — 위키백과·회사 연혁
- 실란 자연발화, SF₆ 대기수명 최대 3,200년·GWP 23,500(IPCC AR5), 공장 정지 시 웨이퍼 폐기 — KISTI·GHG Protocol·MBC
- 화면에 «안 쓴» 것: 매출·임직원 수(출처마다 다름), 우한 법인 연도(2017/2019 충돌 → 2019 사용), 고객사 이름

## 다시 만들기

```bash
cd shortform
./fetch-fonts.sh     # Noto Sans KR 400/700/900 · Black Han Sans → fonts/ (약 20MB, 저장소에 없음)
./render.sh          # bgm.cjs(오디오 합성) → par.cjs(프레임 1,680장) → ffmpeg → GST_25th_nothing_happened.mp4
```

필요한 것: node 18+ 와 `playwright` 패키지(+ chromium), ffmpeg(libx264·aac). 시스템에 컬러 이모지 폰트(Noto Color Emoji)가 있어야
🌵🔥🌍🏆 가 그려진다. 렌더 시간은 4코어 기준 약 2.5분.

- **모든 움직임은 `window.seek(t)` 하나의 순수함수다.** 어느 프레임을 몇 번 찍어도 같은 그림이 나온다(rAF·CSS 자동재생 없음).
  장면 시각을 바꾸려면 `scene.html` 의 `T` 표와 `bgm.cjs` 의 큐 시각을 **같이** 고친다.
- 문구를 고치려면 `scene.html` 의 해당 `<section>` 만 고치면 된다. 영어 소자막은 `.en`.
- 나레이션을 얹고 싶으면 아래 대본을 녹음해 `ffmpeg -i GST_25th_nothing_happened.mp4 -i voice.wav -filter_complex "[0:a][1:a]amix=inputs=2:duration=first" ...` 로 섞는다.
