# GST 창립 25주년 숏폼 샘플 — «아무 일도 안 일어난 25년»

`GST_25th_nothing_happened.mp4` · 59초 · 1920×1080 · 30fps(모션블러) · H.264 + AAC(-16 LUFS) · 가로형.
실사·사진·유명 음원 없이 **HTML/CSS/SVG 모션그래픽을 프레임 단위로 캡처**해 만들었고, BGM·효과음은
브라우저(OfflineAudioContext)로 합성했다. 외부 저작권 자산이 없다 — 폰트는 Google Fonts(OFL),
로고는 회사 자산(아래 참조).

## 컨셉

「지난 25년, GST에는 아무 일도 안 일어났습니다.」로 시작하는 반전 서사.
실란은 안 붙었고, SF₆는 안 남았고, 온도는 안 흔들렸고, 공장은 안 멈췄다 →
그 «아무 일»의 뒤에 **스크러버와 칠러**가 있었다(365일 24시간 × 25년 = 약 219,000시간) →
아무 일도 안 일어나게 하려고 꽤 많은 일을 했다(2001 창업 · 2006 코스닥 · 여섯 나라 · 수출의 탑) →
**그 길을 정하고 먼저 걸어 주신 분들, 그리고 모든 임직원** →
「아무 일도 없게 하는 것. 그게 우리가 25년 동안 한 일입니다.」 →
**GST GROUP(GST · EST · ROBOCARE)** · 「다음 25년도, 아무 일 없이.」

패러디는 없다. 웃음은 «담담한 반전»(귀뚜라미·굴러가는 풀·노란 스탬프)에서, 뭉클함은 마지막 15초에서 온다.
규정대로 영상 안에 팀명·제출자명은 없다.

- **실제 CI 의 출처**: 이 저장소의 `report/qbr-template.pptx` 안에 들어 있던 회사 로고(364×121)다.
  외부에서 받은 것이 아니라 회사가 쓰던 양식 파일의 자산이다.
- **어두운 배경용이라 «반전(knockout)» 처리를 했다** — 흰 바탕을 투명으로 빼고, 파란 다이아몬드 마크는
  밝은 파랑으로, 짙은 남색 글자는 흰색으로 바꿨다. 원본의 2단 색 구분은 그대로 지켰다(`make-logo.py`).
  ⚠ **CI 가이드에 반전 버전이 따로 있으면 그 파일을 `logos/gst-white.png` 에 덮어쓰는 편이 맞다.**
  원본 그대로(흰 바탕용)는 `logos/gst-original.png` 로 함께 두었다.
- 슬롯 규약은 하나다 — **파일이 있으면 그 이미지, 없으면 기본 그래픽.** 파일이 없어도 화면이 깨지지 않는다.

## ⚠ 내보내기 전에 반드시 확인할 것

- **경영진 초상은 «닮은꼴»이 아니다.** 얼굴을 지어내지 않기 위해 정장 실루엣(머리 모양·안경으로만 구분)으로 두었다.
  캐리커처를 쓰려면 `portraits/p1.png ~ p4.png`(정사각형, 190px 이상)를 넣고 다시 렌더하면 된다.
- **이름·직함은 공개 자료 기준이다**(2026년 9월 검색). `scene.html` 의 `LEADERS` 배열 한 곳만 고치면
  화면·순서·소리가 따라온다. **행사 전에 사내에서 현재 직함을 확인할 것** —
  틀린 직함이 대형 스크린에 뜨는 것이 이 영상의 가장 큰 위험이다.
- **사내 제출용이다.** 외부 공개·SNS 업로드 전에는 로고·인물·수치 사용을 홍보 담당과 확인할 것.

## 사실 근거(전부 공개 자료 · 확인된 것만 화면에 썼다)

- 2006-02-01 코스닥 상장, 공모가 5,800원·시초가 7,800원(+34.5%) — 이투데이
- 해외 법인: 미국 2006 · 시안 2013 · 대만·우시 2016 · 허페이 2017 · 우한 2019 · 싱가포르 2020 · 유럽·일본 2024 — 사업보고서·회사 연혁
- 수출의 탑: 5백만불(2007) · 1천만불(2011) · 2천만불(2014) · 3천만불(2019) · 1억불(2021) — 위키백과·회사 연혁
- 칠러: 식각 공정은 ±0.1℃ 수준의 온도제어를 요구한다 — 업계 기술자료·특허. GST 매출의 약 19%가 칠러(2025 3Q)

- 실란 자연발화, SF₆ 대기수명 최대 3,200년·GWP 23,500(IPCC AR5), 공장 정지 시 웨이퍼 폐기 — KISTI·GHG Protocol·MBC
- 계열: ㈜이에스티(EST, 반도체 설비부품·콜드체인) · 로보케어(돌봄로봇, KIST 1호 기술출자기업) — 사업보고서·언론
- 화면에 «안 쓴» 것: 매출·임직원 수(출처마다 다름), 지분율, 우한 법인 연도(2017/2019 충돌 → 2019 사용), 고객사 이름

## 다시 만들기

```bash
cd shortform
./fetch-fonts.sh     # Noto Sans KR 400/700/900 · Black Han Sans → fonts/ (약 20MB, 저장소에 없음)
./render.sh          # bgm.cjs(오디오) → par.cjs(프레임) → ffmpeg → GST_25th_nothing_happened.mp4
SS=1 ./render.sh     # 모션블러 끄고 3배 빠르게 (미리보기용)
```

필요한 것: node 18+ 와 `playwright` 패키지(+ chromium), ffmpeg(libx264·aac). 시스템에 컬러 이모지 폰트가 있어야
🌵🔥🌍🏆❄️ 가 그려진다. 렌더 시간은 4코어 기준 약 12분(SS=3), 4분(SS=1).

- **모든 움직임은 `window.seek(t)` 하나의 순수함수다.** 어느 프레임을 몇 번 찍어도 같은 그림이 나온다.
  장면 시각을 바꾸려면 `scene.html` 의 `T` 표와 `bgm.cjs` 의 큐 시각을 **같이** 고친다 — 한쪽만 고치면 소리와 그림이 갈린다.
- **모션블러는 «3배로 찍어 평균»이다**(`SS=3` → 90fps 캡처 → `tmix=frames=3` → 30fps).
  굴러가는 풀·웨이퍼·색종이가 끊겨 보이지 않게 하는 유일한 방법이다. 끄면 render 는 빨라지지만 눈에 띈다.
- **오디오는 -16 LUFS 로 정규화한다.** 행사장 PA 에서 «소리가 작다»가 안 나오게 하기 위해서다.
- 문구를 고치려면 `scene.html` 의 해당 `<section>` 만 고치면 된다. 영어 소자막은 `.en`.

녹음 파일(`voice.wav`)을 받으면 BGM 을 자동으로 낮춰(ducking) 섞는다:

```bash
FF=$(python3 -c "import imageio_ffmpeg as f; print(f.get_ffmpeg_exe())")
$FF -y -i GST_25th_nothing_happened.mp4 -i voice.wav \
  -filter_complex "[0:a][1:a]sidechaincompress=threshold=0.06:ratio=8:attack=20:release=350[duck];[duck][1:a]amix=inputs=2:duration=first:weights=1 1.6[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k GST_25th_with_voice.mp4
```
